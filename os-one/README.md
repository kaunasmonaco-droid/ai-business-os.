# OS ONE
Free static demo. Open index.html locally. No live AI, checkout, email delivery or personal data collection.

## Launch gates
1. Validate demo with consenting testers; record feedback without unnecessary personal data.
2. Build server-side report generation with source verification, rate limits, cost ceilings and quality checks. Never expose API keys in browser or repository.
3. Implement order IDs, idempotent fulfilment, retry handling and delivery status. Use verified email addresses and consent.
4. Add hosted checkout in test mode only after merchant setup. Verify webhook signatures and payment amount/currency server-side; never trust browser payment status. No live charging until owner approval, legal entity/invoicing, tax and refund rules are confirmed.
5. Add privacy notice, terms, deletion process and applicable consumer digital-content withdrawal disclosures. No unsolicited bulk email.
6. Deploy to staging, test mobile/accessibility, payment failure, duplicate webhook, generation failure and refund paths. Production requires explicit owner approval.
